# React 项目约定

1. 编辑组件或样式前，读取当前仓库和最近目录中的 `AGENTS.md`。
2. 保持组件声明名、文件名、默认导出、具名导出和调用名称一致。重命名时直接更新所有调用方并删除兼容别名。
3. 组件先接收完整 props 对象，再在组件体中解构。
4. props 类型需要复用、较复杂或抽取后能明显提升可读性时，定义具名类型。
5. 为导出的组件、Hook、类型和接口添加文档；为公开 props 的业务属性分别添加文档。
6. 使用 `clsx` 生成动态或组合类名，不要手写字符串拼接、模板字符串拼接或数组 `join`。
7. 样式文件名使用小写 kebab-case，扩展名和预处理器遵循仓库规则。
8. 分离组件样式的布局职责和主题职责；具体文件名、目录和主题表达方式遵循仓库规则。
9. 组件目录之外的页面、布局、路由和业务模块使用 CSS Modules 或 SCSS Modules，不要新增全局业务样式。
10. 将测试放在与源码对应的 `__test__/` 目录；仓库指定其他位置时遵循仓库规则。
11. 修改后运行仓库规定的 typecheck 和 lint 命令。
