# React 项目约定

1. 编辑组件或样式前，读取当前仓库和最近目录中的 `AGENTS.md`。
2. 保持组件声明名、文件名、默认导出、具名导出和调用名称一致。重命名时直接更新所有调用方并删除兼容别名。
3. 当仓库禁止在参数列表中解构时，先接收完整 props 对象，再在函数体中解构。
4. props 类型需要复用、较复杂或抽取后能明显提升可读性时，定义具名类型。
5. 为导出的组件、Hook、类型和接口添加文档；仓库要求时，为每个属性单独添加文档。
6. 项目规范要求时，使用 `clsx` 生成动态或组合类名。
7. 按仓库约定分离组件的布局职责和主题职责。
8. 仓库要求时，在组件目录之外使用 CSS Modules 或 SCSS Modules；不要引入违反仓库规则的全局样式。
9. 将测试放在仓库指定的位置，通常是与源码对应的 `__test__/` 目录。
10. 修改后运行仓库规定的 typecheck 和 lint 命令。
